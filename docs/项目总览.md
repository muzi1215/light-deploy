# Light Deploy 项目总览

> 版本基线：2026-09-02 ｜ 文档状态：与代码当前进度一致，每个模块交付后更新

## 1. 项目定位

Light Deploy 是面向中小企业的轻量化部署发布平台。采用 Spring Boot 单体架构，通过 SSH/SFTP 管理多台 Linux 目标服务器，支持 DOCKER / JAR / STATIC 三种运行时的构建与发布。

- 规模基线：至少纳管 6 台服务器，支持不同服务器上的项目并发发布；
- 同一台服务器同一时刻默认只执行一个发布任务；
- 与已上线的 AIops 系统联动：发布期间自动开告警静默窗口，发布稳定后关闭，并提供发布风险建议；
- 平台自身以 Docker 作为主要交付方式。

### 已完成模块要点

**服务器模块**：SSH 凭据 AES-GCM 加密落库（ciphertext 只写不读）、认证类型/环境标签/状态三枚举、标准六接口、软删除。

**项目模块**：项目→环境→目标服务器三层发布拓扑；RuntimeType / SourceType / BuildMode / DeployStrategy / EnableStatus 五枚举；编码唯一性、GIT 来源强制 gitUrl、JSON 配置格式校验、删除引用保护、主目标互斥（事务内自动降级旧主目标）、跨模块校验注入对方 Mapper 避免循环依赖。

**前端工程**：Vue3 管理端（lighit-deploy-ui），假登录 + 二级静态菜单；服务器/项目/环境/部署目标/任务列表五个管理页对接后端接口，表单校验与后端规则镜像，搜索框支持回车查询；vite 代理 /api → 2027/deploy，typecheck 与生产构建均通过。

## 6. 后续开发路线

按数据依赖链推进，顺序如下：

1. **任务执行器 + SSH 连通性测试**：基于线程池实现执行器骨架，消费任务模块状态流转方法（markRunning/updateProgress/markSuccess/markFailed），落地 SERVER_TEST 连通性测试——消费 server 模块凭据建立真实 SSH 连接，日志实时滚动，第一个端到端可演示功能；
2. **凭据 + 镜像仓库模块**：补齐 project.git_credential_id 引用校验，Git 拉取与镜像推送凭据就绪；
3. **构建模块**：build / build_artifact，Git 拉取 → 分层 Docker 构建（AIops 项目同款 base+app 模式）→ 产物登记；
4. **发布模块**：release_record / deployment / deployment_target，消费项目模块定义的拓扑，实现单目标/全量/滚动三种策略、健康检查、版本回滚；
5. **AIops 集成**：发布前开静默窗口（自动过期）、稳定后关闭、失败风险建议；
6. **收尾**：audit_log 审计、user 过渡登录（前端同步切换真实登录接口）、Docker 化交付与 Nginx 托管前端静态文件。

## 7. 关键开发约定（摘要）

完整约定见项目根目录 `agents.md`，此处仅列高频项：

- 纯 CRUD 不建 Service 接口，`XxxService extends ServiceImpl`；
- Controller 只做参数接收/校验/调用 Service/包装响应，请求 DTO、响应 VO，不暴露实体；
- 主键统一 `IdGenerator.generateUUID()`，禁止 `UUID.randomUUID()`；
- 删除一律软删除，唯一冲突抛 `DATA_CONFLICT(4005)`；
- 凭据只在执行前短暂解密，日志/响应/数据库不出现明文；
- 数据库脚本手工执行，`spring.sql.init.mode` 保持 `never`；
- 每模块交付必须同步中文模块文档（AGENTS.md §13.2）并完成模型层字段注释精化（AGENTS.md §13.1），本文档进度表同步更新；
- Java 代码或模板修改后至少执行 `mvn -o -q -DskipTests compile` 验证。

## 8. 最终效果预期

一台平台服务器（单容器）纳管 6+ 台目标机。运维在页面上完成：登记服务器（凭据加密落库）→ 建项目（选运行时与构建模式）→ 绑定项目到环境的目标机器 → 选版本一键发布。发布过程日志按阶段实时滚动，AIops 静默窗口自动开启；健康检查通过才标记成功，失败按策略停止后续批次，支持回滚到任意保留版本（retain_release_count 控制保留数）。全程无需人工 SSH 登录目标机。

一句话定位：**把手工 SSH 部署脚本，变成一个团队都能安全使用的平台。**
