Light Deploy

轻量部署发布平台
在线

通过 SSH/SFTP 纳管多台 Linux 服务器，统一支持 JAR / Docker / Static 三种运行时。 登记服务器 → 建项目 → 绑目标机 → 选版本一键发布，构建、发布、回滚一站式，健康检查通过才算成功。

三种运行时构建发布分离版本回滚实时日志操作审计AIops 联动
Java 21 · Spring Boot · Vue3 访问平台 →

AIops

智能运维平台
在线

面向中小团队的运维闭环：SSH 巡检采集 → 规则引擎判警 → 告警自动转工单 → AI 分析 / RAG 知识库 → ECharts 数据大屏。 让一个人也能管好几十台服务器。

巡检告警工单闭环RAG 知识库数据大屏多模型 AI
Python FastAPI · Vue3 访问平台 →

Auth Cloud

发布 × 运维联动

Light Deploy 发布时在 AIops 开静默窗、推送发布事件；AIops 侧据此对发布窗口告警降噪，并保留完整发布留痕。

实时状态可见

Light Deploy 首页读取 /aiops/status（默认 30s 轮询），实时展示联动总闸与 AIops 对端是否可达，异常一眼可见。

统一鉴权（规划）

Auth Cloud 上线后，两个系统的登录、角色权限与动态菜单统一收口，用户一次登录即可按权限进入各自产品。
